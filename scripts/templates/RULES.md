# RULES

## 사용법
- 공식 정책과 명시적 승인에서 작업 제한을 요약하고 출처·확인일을 기록한다. 요약이 원문과 다르면 원문을 따른다.
- 공식 정책에서 포괄적으로 허용한 대상군은 개별적으로 열거되지 않아도 in-scope로 판단한다.
- 명시된 out-of-scope는 해당 허용 범위에서 제외한다.
- 포괄적 허용 범위 자체가 불명확한 대상만 사용자에게 확인한다.
- 정책·승인 조건이 바뀌면 갱신한다. 서비스 영향, 예상치 못한 민감정보 노출 또는 범위 이탈을 발견하면 관련 작업을 중단하고 사용자에게 알린다.
